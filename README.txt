CSS SELECTORS PRACTICAL
=======================

Files included
--------------
1. index.html - the webpage structure and content
2. style.css  - the CSS styling rules
3. README.txt - these instructions

How to run
----------
1. Extract CSS_Selectors_Practical.zip.
2. Keep index.html and style.css in the same folder.
3. Double-click index.html to open it in your web browser.
4. If you edit either file, save it and refresh the browser.

Requirements demonstrated
-------------------------
- External stylesheet connected with <link rel="stylesheet" href="style.css">
- Body background colour
- Three heading tags using class="head"
- Class selector: .head
- ID selector: #bg-alpine
- Background colour on the second heading
- Red text on the second heading
- Paragraph element selector: p
- Second paragraph styled using id="para"
- Descendant selector: #para strong
- Font size and text colour styling
- Ordered and unordered lists
